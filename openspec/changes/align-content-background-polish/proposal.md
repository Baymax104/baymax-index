# Align Content Background Polish

## 背景

当前项目已补齐线上首页的 About、GitHub pinned 和留言板结构，但内容区背景仍偏纯色。线上版本在浅色内容区中有低对比度网格、短线段和少量散点，用于让卡片外部空间更接近截图效果。

## 目标

- 在 Hero 之后的内容区增加浅色背景装饰。
- 装饰必须位于内容和 Footer 之后层级的下方，不影响交互。
- 保持现有 About、GitHub 和留言板版块结构不变。

## 非目标

- 不新增动态粒子或运行时随机装饰。
- 不改变 GitHub 数据获取、giscus 配置或 Hero 主要交互。
- 不引入新的视觉依赖。
